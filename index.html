I wanted a nicer Minecraft launcher, so I made one.

DN Launcher is free and runs on Windows. It handles your instances, mods and servers, and it comes with my DN UI mod built in. I made it for me and my friends. You're welcome to use it too.

What it does

Nothing magic. It's a launcher, it just tries to be a nice one.

One instance per way you play

Every instance has its own mods, resource packs, shaders and worlds, so your modded survival never breaks your vanilla one.

  • Turn mods on and off with a switch, or update them all at once
  • Rename, duplicate, export as a .mrpack, or repair
  • Set Java and RAM per instance if you want

Mods from Modrinth and CurseForge

Search, pick, install. It only shows what works with the instance you're on, and it grabs the dependencies for you.

A launch screen that tells you what's going on

You see what it's downloading, how far along it is, and how long you've been playing once you're in. No more staring at a frozen window wondering if it crashed.

DN UI in one click

My UI mod for Fabric 1.21.11. Add it to an instance from the Mods tab; Fabric API comes with it.

Photosensitivity mode

One switch turns off flashing in the launcher and in game: hit flashes, totem pop, lightning, screen shake.

French or English

Switch in Settings. A few themes too, including a black-and-white one.

Is it safe?

Fair question for an .exe from a site you've never seen. Here's what it does with your stuff.

Your password never goes through it. You log in on Microsoft's own page, the same one the official launcher uses. The launcher only gets permission to start the game.

Nothing is collected. No ads, no analytics, no account of mine to sign up for. There's no cracked mode either; you need to own the game.

Downloads come from the usual places. The game and Java from Mojang, Fabric from fabricmc.net, mods from Modrinth and CurseForge.

It uninstalls normally, from Windows Settings › Apps. Your files are in %APPDATA%\DN Launcher.

Want to make sure your download is the real file? Open PowerShell in your Downloads folder and run Get-FileHash .\DN-Launcher-Setup.exe. The result should match:

Installing it

  1. Download the installer from the button at the top.
  2. Open it. Windows will most likely show the blue box on the right. Click More info, then Run anyway.
  3. Sign in with the Microsoft account you play Minecraft on.
  4. Press Play. The first launch downloads the game, so give it a minute.

Is it free?

Yes. No paid version, no ads.

Installer or portable?

The installer puts it in your Start menu and in Windows' app list. The portable one is a single .exe you can run from anywhere. Both are the same launcher.

Can I keep my mods from another launcher?

Yes. Drop your .jar files into an instance, or import a Modrinth modpack (.mrpack).

How do I update?

Download the new installer from here and run it. It replaces the old version and keeps your instances, worlds and settings.

Something broke

Open the instance, go to the Log tab, and send me what's there. The launcher also shows the log on its own when the game crashes.
